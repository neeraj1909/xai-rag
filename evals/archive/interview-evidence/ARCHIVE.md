# Historical interview evaluation evidence

This archive preserves the XAI-RAG interview-materials snapshot and its `evaluation/` directory. Its reports, fixtures, result files, scripts, and source snapshots document different experiments and revisions; their scores and denominators must be interpreted in the context of each run. The archived `README.md` and other Markdown files reflect the original interview-materials layout, not the current project documentation.

The scripts are historical evidence, not supported reproduction commands. Some contain absolute paths to the former interview-materials directory, assume specific fixtures or model versions, and may call paid APIs. Review their inputs, paths, dependencies, model access, and cost before running them. Use the project's current evaluation documentation for supported workflows.

`cdp-browser-evidence.md` records a browser check of the local Swagger/OpenAPI interface against an isolated fixture. It is not evidence of live retrieval, a live model call, or production deployment.

The original files were copied byte-for-byte from the interview-materials repository and checked with SHA-256. That integrity check does not establish that historical scripts work in this location or that any result can be reproduced unchanged.

# Final local E2E validation

The final positive black-box test on 20 November 2026 passed **one test in 84.63 seconds**, using a simple one-sentence source, scoped ingestion and replay, REST, SSE and four concurrent requests. Its measured concurrency p50 was **27.10 seconds** and maximum was **35.00 seconds**, only for those four requests. Auth probes returned 401 for an unauthenticated query and 403 for both ungranted ingestion and reader ingestion. Empty-grant and other-tenant probes returned no sources or retrieval explanations. These small checks do not establish absence of all unauthorized disclosure or production throughput.

The API image was a **current-source overlay on an existing dependency image**, not a fresh build of the repository's Dockerfile. A test wrapper explicitly started Uvicorn with 15-second keepalive. Chroma and Elasticsearch were real disposable local services, the NLI was real, and generation/grounding used a deterministic local provider stub; this was not an OpenAI quality evaluation. The test-only ES node required its disk watermark disabled. The manifest records the Python-source digest `bcab9f293c3c7feb82915390ee3d6161416afd142ca39a4534e7f682c3856c3b`; it does not by itself archive a complete deployable environment.

Do not discard the two previous attempts. `e2e.log` records a failed request while a model was absent from the offline cache; `e2e-retry.log` records a later test failure when the original Markdown sample caused a false refusal. The latter is examined separately in [the literal-claim probe](../nli-literal-e2e/README.md). The positive final run used a simpler source; it does not erase the Markdown failure.

`cleanup.log` records removal of the owned API, store and stub containers, test network and temporary overlay image. The selected artifacts do not include the `.env`, local policy or full API logs and were checked for common secret patterns and configured secret values. This is a best-effort scan, not a complete privacy audit. File paths and captured sample text are non-secret project/test material. The original test harness must be adapted for fresh isolated resources before use elsewhere.
